# WebPageMidToFin Portfolio

A static, frontend-only portfolio for Kennith Albo Pioquento.

## Run locally

Open `index.html` directly in a browser, or serve this folder with any simple static-file server.

## GitHub Pages

This project is compatible with GitHub Pages because it uses only HTML, CSS, JavaScript, static assets, and browser `localStorage`.

## Project structure

- `index.html` — single-page portfolio markup
- `css/` — main styling, animations, responsive layout
- `js/` — theme, products, projects, activities, and global interactions
- `Assets/` — profile, logo, perfume photos/posters, and placeholders for future project/activity screenshots

No backend, database, Firebase, PHP, Node.js backend, authentication, checkout, or server-side form processing is used.
